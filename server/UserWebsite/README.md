# 中传校园助手 · 普通用户网站

页面在 [client/UIF](../../client/UIF)，网站服务器使用 Node.js 24，无需安装 npm 依赖。网站与浏览器同源，业务请求统一发给 [UnifiedInterfaceManagement](../UnifiedInterfaceManagement/README.md)。账号、实例、会话、消息和运行记录由 MainAgent 保存在 PostgreSQL。

## 启动

先为 MainAgent 配置已迁移的 PostgreSQL，并准备 llmServer 和统一接口管理器。邮箱验证和密码重置邮件由 MainAgent 的 SMTP 配置发出。 [MainAgent 部署和认证](../MainAgent/main_agent/cloud/README.md#安装与迁移)

在主管理器中执行 `start user-website` 会按依赖启动 MainAgent、统一接口管理器、CAS 和安卓下载服务。手动启动时，需要在另一个进程中执行 `node ../AndroidAppServer/server.mjs` 以提供 APK 下载。

在主管理器中执行 `start core` 可同时准备 MCP、RAG 查询和教师凭据服务。校务功能依赖 `start mintagw` 启动的模拟服务。首次部署或更新教室模拟服务时，在 `simulation/Classroom` 执行 `dotnet build`，由主管理器加载 Debug 产物。首次部署和升级时，用 MainAgent 的迁移命令更新 PostgreSQL。 [数据库迁移步骤](../MainAgent/main_agent/cloud/README.md#安装与迁移)

```powershell
node --env-file-if-exists=.env server.mjs
```

启动后可打开本机 8082。自定义端口或上游时，将 `.env.example` 复制为 `.env` 后修改。端口改变时，若配置了 `USER_WEB_PUBLIC_URL`，同步调整其端口。 [本地网站](http://127.0.0.1:8082/)

同一局域网的设备可以通过主管理器发布的 HTTPS 入口访问。在本机控制台输入 `external help` 查看命令。 [主管理器对外服务配置](../../MainProcessManager/README.md#对外服务管理)

| 环境变量 | 默认值及用途 |
| --- | --- |
| `USER_WEB_HOST` | `127.0.0.1`，Node 监听地址 |
| `USER_WEB_PORT` | `8082`，Node 监听端口 |
| `USER_WEB_PUBLIC_URL` | 本机 8082 或所配置的端口，须与浏览器使用的对外源完全一致 |
| `USER_WEB_CAS_PUBLIC_URL` | 自建 CAS 的独立 HTTPS 源地址，主管理器启动内网或 FRP 入口时自动传入 |
| `USER_WEB_UIM_URL` | `http://127.0.0.1:8090`，统一接口管理器的 HTTP 入口 |
| `USER_WEB_TRUSTED_PROXY` | 可选。前置 TLS 代理的单个 IP，用于接受该代理重设的客户端 IP |

## 在线管理台

在现有网站地址后加 `/admin`。本机入口为 [后台管理](http://127.0.0.1:8082/admin)，局域网沿用网站的 HTTPS 地址。用户先在普通站点完成邮箱验证、校园身份绑定和个人资料登记。本地超级账户在主管理器执行 `admin grant <用户UUID>`，授权后用原邮箱和密码登录。 [本地命令](../../MainProcessManager/README.md#在线管理员)

| 页面 | 范围 |
| --- | --- |
| 运行总览 | 所有登记进程和 PID。受管校园后端、RAG 查询、MCP 和独立 Worker 的启停、重启 |
| 用户与业务数据 | 按用户 ID、邮箱或名称定位用户。启停账号、改名、撤销登录、管理实例与会话，查看消息、任务和校园身份。校务办理支持核对、取消和归还 |
| 校园服务后端 | 查看 MINTA 上游，按用户 UUID、学院和年级管理服务黑白名单，设置教室占用与开放范围，审核或撤下社团 |
| 公众号采集 | 查看微信读书登录状态，可随时打开二维码扫码登录 |
| 地点照片审核 | 展开地点的照片列表，按状态筛选、预览、审核或永久删除单张照片。校园地图投稿单张最多 20 MB |
| RAG 资料库 | 资料范围、文档查看、文本和文件导入、删除和检索 |
| 工具调用 | SubSkill 与 MCP 的注册清单、负责的子智能体和可用的 MINTA 办理动作 |
| 校园资料核验 | 查看绑定邮箱、核验校园资料和解除绑定。学工号账号及其密码由 CAS 独立管理台管理。 [CAS 独立管理台](../CASserver/README.md#管理与协议切换) |
| 路由管理、教师凭据、管理审计 | 修改子智能体介绍与路由反馈，管理样本和教师凭据，查看近期管理操作 |

角色和职称编辑使用专用的 `CLOUD_ADMIN_ROLE_DATABASE_URL`。在 PostgreSQL 中由数据库所有者为这个连接分配窄权限，配置后管理台会显示「角色与职称」。现有的本地 `set-user-role` 命令也可分配角色。 [本地角色命令](../MainAgent/main_agent/cloud/README.md#学生和老师身份)

```sql
CREATE ROLE campus_role_editor LOGIN;
\password campus_role_editor
GRANT CONNECT ON DATABASE cloud_agent TO campus_role_editor;
GRANT USAGE ON SCHEMA public TO campus_role_editor;
GRANT SELECT (id), UPDATE (role, academic_title, updated_at) ON public.users TO campus_role_editor;
GRANT INSERT (user_id, action, outcome, subject_hash) ON public.audit_events TO campus_role_editor;
GRANT USAGE ON SEQUENCE public.audit_events_id_seq TO campus_role_editor;
```

管理会话绑定到本次邮箱登录。闲置 15 分钟或登录满 4 小时后需重新登录。主管理器撤销权限后，该用户已有的管理会话随即失效。管理请求与操作记录由统一接口管理器处理。 [在线管理接口](../UnifiedInterfaceManagement/README.md#在线管理接口)

## 普通用户流程

- 访客可在欢迎页、登录或注册窗口查看隐私说明（站点路径为 `/privacy`）。登录后也可从设置进入。地图投稿和日历订阅提供对应的说明入口。CAS 认证服务和安卓应用分别提供自己的隐私说明。
- 校园应用抽屉可按应用名或关键词搜索。桌面键盘输入后可用回车打开唯一匹配项。
- 首页首屏展示欢迎图文。向下滚动一次或在手机上向上滑动一次，即可进入聊天工作台。点击工作台侧栏顶部的站点名称可回到首屏。
- 桌面工作台先铺满窗口。滚动到位后，侧栏从左侧滑入，工作台同步右移并按可用宽度调整控件布局。向上返回欢迎页时，侧栏收回，工作台恢复全宽。
- 聊天输入栏横跨工作台底部，桌面上的传传面板在输入栏上方结束。
- 新建会话的主工作台在导航旁显示原版 Live2D 校园助手，窄屏时在聊天内容上方优先展示角色栏。首次进入时播放静音的音波入场，角色视线跟随网页内的鼠标。点击时播放点头或摇头动作。模型、贴图和动作由网站同源提供，浏览器使用 WebGL 渲染。点击角色栏的关闭按钮可隐藏模型，在「设置 → 外观 → 显示传传模型」恢复。浏览器会记住选择。
- 打开会话时，Q 版传传会鞠躬。等待回复时播放读书动作，轻点或收到回复时播放笑脸。拖动后松手贴到最近的一边，轻点会显示随机问候气泡并将焦点移到输入框。开启系统的减少动态效果时，角色保持静态并可点击问候。
- 点击传传会直接显示随机问候。学生称为「同学」，教师按登记姓名取姓，例如「欧阳老师，您好！」。姓氏无法识别时使用「老师，您好！」，访客会收到通用问候。
- 欢迎页三环在悬停和向下滚动时旋转。滚动触发后，三环开口保持朝左，回到首屏顶部时恢复初始朝向。鼠标经过欢迎页文字区域时会显示随指针移动的反色圆，进出文字区时渐显渐隐。
- 侧栏底部的「设置」包含外观和账号。访客也可调整外观，并在账号区登录或注册。手机上先打开左上角的会话导航。
- 邮箱验证后先绑定校园统一身份，再登记姓名、学号、学院和年级。教师登记姓名、工号和学院。通过校园入口和邮箱入口登录会进入同一个用户 ID。「设置 → 账号 → 个人资料」可编辑资料和称呼。
- 「设置」的「外观」支持切换预设主题。选中「自定义」后可修改配色，设置本机 PNG、JPG 或 WebP 作为工作台背景图，并调节 0–100% 不透明度。切回「自定义」时恢复本浏览器保存的图片和不透明度。
- 顶栏默认使用登记姓名，也可使用自己设置的称呼。学生加「同学」，教师加职称，职称空缺时称「老师」。 [账号身份管理](../MainAgent/main_agent/cloud/README.md#学生和老师身份)
- 支持 QQ、网易、Gmail 和 Outlook 邮箱注册。注册后或未验证账号登录时进入邮箱验证。验证令牌有效 10 分钟，邮件重发间隔 60 秒。新密码须为 8–128 个字符，包含数字和小写英文字母。 [注册域名和发件配置](../MainAgent/main_agent/cloud/README.md#邮件服务商)
- 在「设置」的「账号」中点击「修改密码」打开改密面板。先填当前密码并发送验证令牌，再填写邮件令牌和新密码保存。成功后需要重新登录。
- 邮箱登录后会引导未绑定的用户完成校园统一认证。通过内网和 FRP 使用自建 CAS 时，浏览器会跳转到独立 CAS 地址，输入学工号和 CAS 密码后，回到原网站完成绑定。CAS 验证过的学工号会自动带入个人资料。 [自建 CAS](../CASserver/README.md) · [协议与回调要求](../MainAgent/main_agent/cloud/SSO.md)
- 每个账号自动获得私有默认实例。侧栏「管理」可编辑任一实例，支持改名、设为默认、暂停、恢复和删除。暂停时可查看历史，恢复后 Worker 继续领取排队任务。
- 发出第一条问题时创建会话。侧栏按标题搜索当前实例的历史，也可以从会话列表或聊天标题旁打开「管理会话」改名和删除。删除确认会列出影响范围。运行中的任务结束后才能删除相关会话或实例，删除最后一个实例会补建空的默认实例。 [实例和会话接口](../UnifiedInterfaceManagement/README.md#账号实例对话和运行)
- 聊天内容左侧每轮提问有一个跳转刻度。聊天滚动时，当前刻度到达可见区域的上沿或下沿后，刻度列表在栏内继续滚动。也可以单独滚动刻度列表浏览历史，继续滚动聊天时会恢复跟随。悬停或键盘聚焦可预览，点击或按 Enter 跳到提问。顶部的上箭头可加载更早记录，键盘可用上下键移动焦点。
- 输入框支持建议协作角色，MainAgent 决定是否调用并给出最终回复。
- 排队或生成中的会话在左侧显示沿边框流动的光，切到其他会话后仍显示进度。任务结束后，网站从会话历史读取已保存的回复。当前会话最新一轮结束后可点「重试」，在原位置更新回答。已办理的校务沿用原回执。
- 「撤回」只出现在当前会话最新一轮，排队和生成中也可使用。校务操作按执行的相反顺序逐项弹窗，全部同意后才开始撤销。任意一步点「取消撤回」即退出确认。全部撤销成功后移除本轮消息，上一轮随即成为最新一轮。如果有操作暂时无法撤销，本轮仍保留，可重新检查剩余步骤。 [撤回接口及回执](../MainAgent/main_agent/cloud/README.md#重来与撤回)
- 提交状态不明确时，「重试提交」使用原来的幂等键和内容。
- 助手回复和历史回复支持 Markdown，包括标题、列表、代码、链接和表格。原始 HTML 按文字显示，图片标记显示替代文字。解析器采用随网站分发的 `markdown-it` 15.0.3 浏览器构建。 [上游包](https://www.npmjs.com/package/markdown-it/v/15.0.3)

## 校园组件窗口

工作台右侧的「校园应用」侧栏默认收起。点击右边缘中间的按钮展开或收起，可打开地图、个人日程、公众号总成、教室、体育馆、校园活动、社团和图书馆。宽屏展开时聊天区随之调整宽度，小屏使用右侧浮层。登录后可在窗口办理，也可以在问答里用明确的一句话办理，两边使用同一账号和业务记录。

- 「个人日程」支持选择第 1–20 教学周，拖动时间缩放控件可切换一周、一天和小时视图。点击周视图的星期可展开当天日程。周视图显示各节起止时间，连堂跨格展示，小时视图按时钟时间排布。开关的选择按账号保存在当前浏览器。学生和教师各用已核验的学号或工号查看自己的课表或授课安排，课程及节次时间来自本地配置的模拟排课服务。 [校务日程接口](../UnifiedInterfaceManagement/README.md#minta-校园应用)
- 在「校园应用」打开「学期报告」，或在「设置」打开「个人空间」，可查看每门课的模拟成绩和积分、已报名活动及积分总和。各课程和活动的积分按项目编号固定为 1–4 的整数。百分制模拟成绩按学期、账号和课程固定生成，范围为 60–100。课程积分每门只计一次，活动积分随报名确认和取消更新。当前报告对应 2026–2027 学年第一学期，活动按北京时间的开始日期归入学期。
- 「公众号总成」可按文章标题关键词和公众号名称组合搜索。「管理特别关注」可从公众号名录选择和取消关注。设置按登录账号保存，关注文章在当前筛选结果中置顶，同组按发布时间倒序。每篇文章显示北京时间，来源只提供日期时会注明。点有原文链接的标题可打开原文。 [校园日报服务](../CampusDigest/README.md)
- 地图支持滚轮、缩放按钮、双指缩放和拖动。登录后可点地标、下拉选择或点击校区内的自选点位，查看该点所有已通过审核的照片。切到其他点位会移除临时标记和它的下拉项。单张 JPG、PNG 或 WebP 可在地点相册投稿，最大 6 MiB、2400 万像素。在线管理员在「地点照片审核」发布或撤下，公开相册只显示审核通过的内容。地点按约 10 米网格汇总，已有照片的点位有单独颜色。 [地图数据来源](../../DataBase/CampusNavigation/README.md)
- 校园地图可切换 2D 和 3D。3D 视图支持拖动旋转、缩放和点击地标。选择步行起终点后，两种视图都会显示路线，聊天问路也使用同一份路网。
- 教室与体育馆支持预约和取消。预约教室时选择开始和结束时间，学生填写老师姓名和电话，教师使用本人电子凭据。体育馆对两种账号使用同一流程。
- 「教室预约」按北京时间为每间教室显示所选日期的占用时间轴。切换日期、点击刷新或完成预约与取消后会读取最新台账。占用条下标出具体时间，跨日预约在每日的边界截开。
- 「社团」显示本人登记的社团、其他社团的公开资料和本人报名情况。登记人可编辑社团，审核通过后可发布活动。活动也可在「校园活动」中报名或取消。
- 社团登记人可在「我登记的社团」逐项恢复或永久删除自有归档，也可以确认后清空全部自有归档。在线管理员可在「校园服务后端 → 社团与活动 → 社团归档」逐项处理。恢复保留审核状态。永久删除社团会同时删除所属活动和报名，永久删除活动会删除该活动的报名。
- 「图书馆」显示各馆藏的在馆和借出数量，以及当前可借、可归还或等待归还的下一步。窗口打开时每 5 秒自动刷新。个人借还记录只向本人展示。

社团登记和介绍修改进入待审。审核通过后，校园应用和智能体按负责人设置的年级与学院展示社团及活动。按年级或学院限制时，以管理员在 CAS 管理区核验的资料为准。教室手工占用会暂停新预约，恢复开放后按已有预约判断实时空闲状态。

负责人也可在问答中提交明确的社团修改。例如「修改社团摄影社，开放年级：大一、大二，开放学院：新闻学院」。单项可填「不限」。

校务办理使用项目内 MINTA 模拟服务。 [校务接口与返回字段](../UnifiedInterfaceManagement/README.md#minta-校园应用)

个人日程按北京时间显示课表、本人已报名的活动、已确认的教室时段和自定义事件。点「新增事件」填写名称和起止时间，可选填地点。点自定义事件卡片即可编辑或删除。课程、活动、预约和自定义事件发生重叠时，三种视图都会标出「时间冲突」。隐藏课表后，课程时间仍参与检查。前一项结束和后一项开始是同一时刻时可正常衔接。

活动详情可跳到「校园活动」的对应卡片，报名、取消或改期后会同步更新。发布和修改活动时须填写精确到分钟的起止时间。历史活动缺少时段时，登记人可在「社团」补全，已有报名继续关联原活动。取消教室预约后，该时段会从个人日程移除。仅有旧预约登记而缺少起止时间的记录没有可显示的时段。

### Windows 和安卓日历同步

打开「校园应用 → 日历同步」，也可从「个人日程」点「同步到日历」。学生同步整学期课表，教师按核验工号同步授课安排，两种身份均同步本人已报名且可见的校园活动、教室预约和自定义事件。

- **Windows 和安卓上的 Microsoft To Do** 安装应用后用计划同步的微软账号登录。回到校园助手点「连接 Microsoft To Do」，用同一账号同意授权。回到网页后会自动同步，也可点「立即同步」。在 Microsoft To Do 的清单列表中打开「中传校园日程」，点开任务可查看起止时间和地点。 [官方下载](https://www.microsoft.com/zh-cn/microsoft-365/microsoft-to-do-list-app) · [跨设备登录说明](https://support.microsoft.com/zh-cn/todo/syncing-your-microsoft-to-do-account)

## 网站会话

浏览器持有 HttpOnly Cookie，访问令牌和刷新令牌由网站进程持有，并按登录会话串行更新。邮箱密码登录时勾选「记住我」，同一浏览器可保持登录最多 30 天。网站进程重启后可通过 PostgreSQL 中的有效会话恢复。退出登录或修改密码后需要重新登录。建议在个人设备上勾选。

公网部署使用 HTTPS，由前置代理终止 TLS 并保留网站的对外 `Host`。如需转发客户端地址，将 `X-Forwarded-For` 重设为单个客户端 IP，并配置 `USER_WEB_TRUSTED_PROXY`。网站用配置的对外协议向统一接口管理器发送 `X-Forwarded-Proto`。若该跳走本地 HTTP，生产环境需要让统一接口管理器信任网站地址，再让 MainAgent 信任统一接口管理器地址。 [统一接口管理器代理设置](../UnifiedInterfaceManagement/README.md#windows-启动)
